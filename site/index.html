I know this site isn't great

I'm working on it. So far, this site has only HTML and CSS. I'm not pulling in any external libraries as of now.

The goal of this exercise is to practice Semantic HTML and organizing my CSS. I know it's not pretty, but it's a start.

I've spent time working on websites in React and Next.js, as well as JQuery. I know there are static site generators such as MkDocs, Hugo, and Jekyll, which would make my life easier in this endeavor, but easy is not the goal. I want to learn how to utilize what is already available in the browser. Avoiding the addition of Javascript until absolutely necessary or in a fitting scenario.

I've always wanted to start from Vanilla and build something I can be proud of. So far it's not there, and the shell-like theme is just a spur of the moment idea.

My goals for this site include:

  • Document the process I went through to learn this at: Blog > Creating my personal site
  • Fix the nav bar so it's less ugly
  • Learn to create custom HTML elements with Javascript, when appropriate
  • End up with a place where I can write about my projects, adventures, and anything that comes to mind so that they can be shared with others
